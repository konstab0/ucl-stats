# UCL Stats

A React app for football fans to follow recent UEFA Champions League results, the current season's standings, and top scorers.

## Live site

https://konstab0.github.io/ucl-stats/

## API

Match and competition data comes from [football-data.org](https://www.football-data.org/documentation/quickstart/) and is accessed through a Cloudflare Worker.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/konstab0/ucl-stats.git
   cd ucl-stats

2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm run dev
```bash

4. Open the link in your browser
